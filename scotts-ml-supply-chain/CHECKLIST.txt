📋 STEP-BY-STEP CHECKLIST:

□ STEP 1: Install Python (5 minutes)

  Option A - Microsoft Store (EASIEST):
    1. Press Windows Key
    2. Type: "store"

    4. ☑️ CHECK "Add Python to PATH" (IMPORTANT!)
    5. Click "Install Now"

□ STEP 2: Close PowerShell (Important!)

    - Close ALL PowerShell windows
    - Open a NEW PowerShell
    - (Windows needs to reload settings)

□ STEP 3: Verify Python Works

    In NEW PowerShell, type:

    Python 3.11.7

    ❌ If no → Reopen PowerShell and try again

    pip install numpy pandas scikit-learn scipy joblib

    Wait 2-3 minutes for download/install

□ STEP 5: Verify Packages Work

    python -c "import numpy, pandas, sklearn; print('Success!')"

    You should see:
    Success!

    ✅ If yes → Continue to Step 6
    ❌ If no → Try: python -m pip install numpy pandas scikit-learn scipy joblib

□ STEP 6: Navigate to Project

    cd C:\Users\Nick\Cornell-Machine-Learning\scotts-ml-supply-chain

    (Adjust path if your project is elsewhere)

□ STEP 7: Run the Demo
