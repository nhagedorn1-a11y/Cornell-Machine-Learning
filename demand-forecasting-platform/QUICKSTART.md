## **Option 1: Quick Test (No Docker Required)**

Perfect for: Testing the API locally without infrastructure

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate sample data
python scripts/generate_sample_data.py

# 3. Run API tests
python test_api.py

# 4. Start the API server
uvicorn services.api_gateway.main:app --reload

# 5. Open browser
http://localhost:8000/docs
```

**What you get:**
- Working REST API with all endpoints
- Interactive Swagger docs
- Mock forecasting service
- Sample data ready to use

## **Option 2: Full Stack with Docker**

Perfect for: Production-like environment with databases

### Prerequisites
- Docker Desktop installed
- 8GB RAM minimum
- Windows/Mac/Linux

### Steps

```bash
# 1. Setup environment
cp .env.example .env
# Edit .env and add your API keys (optional)

# 2. Start all services
docker-compose up -d

# Wait 30 seconds for services to initialize

# 3. Check health
curl http://localhost:8000/health/detailed

# 4. View services
# API:     http://localhost:8000/docs
# MLflow:  http://localhost:5000
# DB:      localhost:5432
```

### Service Status
```bash
docker-compose ps

# Should show:
# - forecasting-db (PostgreSQL/TimescaleDB)
# - forecasting-redis (Redis)
# - forecasting-mlflow (MLflow)
# - forecasting-api (FastAPI)
```

## **Quick API Examples**

### Generate Forecast
```bash
curl -X POST "http://localhost:8000/api/v1/forecast" \
  -H "Content-Type: application/json" \
  -d '{
    "date_range": {
      "start": "2026-02-01",
      "end": "2026-03-31"
    },
    "sku_ids": ["SKU-001", "SKU-002"],
    "location_ids": ["DC-ATL", "DC-CHI"],
    "confidence_level": 0.95
  }'
```

### Optimize Inventory
```bash
curl -X POST "http://localhost:8000/api/v1/optimize/rebalance" \
  -H "Content-Type: application/json" \
  -d '{
    "current_inventory": {
      "DC-ATL": {"SKU-001": 200},
      "DC-CHI": {"SKU-001": 800}
    },
    "constraints": {
      "budget": 50000,
      "max_transfers": 10
    }
  }'
```

### Get Metrics
```bash
curl http://localhost:8000/api/v1/metrics/dashboard
```

## **Troubleshooting**

### "Module not found" errors
```bash
pip install -r requirements.txt
```

### Docker services not starting
```bash
# Check logs
docker-compose logs -f

# Restart services
docker-compose down
docker-compose up -d
```

### Database connection errors
```bash
# Check PostgreSQL is running
docker-compose ps postgres

# Check .env file has correct DATABASE_URL
cat .env | grep DATABASE_URL
```

### Port already in use
```bash
# Kill process on port 8000
# Windows:
netstat -ano | findstr :8000
taskkill /PID <PID> /F

# Mac/Linux:
lsof -ti:8000 | xargs kill -9
```
